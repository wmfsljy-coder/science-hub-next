**2026-11-08** 새 교사용 사이트 시범판을 만들었다. Next.js 16(App Router, 정적 내보내기) + TypeScript + Tailwind v4 로 홈(과목 카드 12개, 즉시 검색, 학년·과목군 큰 버튼), 과목 페이지(단원 카드, 수업 열기), 단원 페이지(지도안 전문, 수업 흐름 단계, 차시 한눈에, 성취기준, 학생 입장 QR 크게 띄우기)를 만들었다. 내용은 `scripts/fetch-content.mjs` 가 과목 저장소 12개의 index.html·LESSON.md·precheck-items.js 를 읽어 `content/generated.json` 으로 모으고, 대표 그림은 sharp 로 480px 로 줄인다(44단원 모두 추출, 성취기준·차시·구성 숫자 빠짐 없음). `npm run build`·`npm run lint` 통과, 로컬 서버에서 홈·과목·단원·검색·다크 모드·390px 화면을 확인했고 44개 단원 주소가 모두 200 이었다. GitHub Actions 로 Pages 배포(푸시·매일 새벽 3시·수동). 과목 저장소와 예전 허브는 건드리지 않았다. 남은 일: 선생님 사용 후 화면 다듬기, 예전 허브의 qr/·records/·class/ 같은 교사 도구를 이 사이트에서도 연결할지 결정.
